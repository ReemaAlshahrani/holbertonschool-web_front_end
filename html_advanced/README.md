# HTML Advanced - Techium Project

This repository contains the advanced HTML project for Holberton School, focusing on structuring complex web pages, semantic elements, multimedia integration, and styling components according to strict web guidelines.

## Project Structure & Tasks

Here is a summary of the tasks and milestones completed in the `html_advanced` directory:

*   **Setup & Metadata (Tasks 0 - 5):** 
    *   Initialized the repository structure and created base HTML templates with proper character encoding (`UTF-8`) and viewport configurations.
*   **Headings, Paragraphs, and Text Formatting (Tasks 6 - 15):**
    *   Structured semantic content using appropriate heading levels (`h1` to `h6`), paragraphs, lists (unordered, ordered, and definition lists), and blockquotes.
*   **Tables & Advanced Elements (Tasks 16 - 25):**
    *   Implemented data tables with `<caption>`, `<thead>`, `<tbody>`, and scope attributes.
    *   Added interactive elements like `<details>` and `<summary>`.
*   **Layout & Sections (Tasks 26 - 35):**
    *   Built the core sections of the Techium homepage: Hero, Services, Works, About Us, Latest News, Testimonials, and Contact.
*   **Media & Assets (Tasks 36 - 40):**
    *   **Task 36 (`36-index.html`):** Added responsive images and avatars with specific dimensions and alternative text to the Works, About Us, Latest news, and Testimonials sections.
    *   **Task 37 (`index.html`):** Finalized the main homepage (`index.html`) by replacing footer text links with inline SVG icons for social media (Facebook, Twitter, Instagram).
    *   **Tasks 38 - 40 (`styleguide.html`):** Developed and finalized the comprehensive styleguide (`styleguide.html`) featuring:
        *   **Video Player:** Embedded Big BuckBunny video with controls, loop, and a poster thumbnail.
        *   **Audio Player:** Embedded an audio file with standard playback controls.
        *   **Iframe:** Integrated an embedded YouTube video iframe for Holberton School.
